# Telecom-X
Projeto Aluro para entender, atraves de dados, fatores que levam a perda de clientes

📊 Plano de Execução da Análise

    1) Extração (E — Extract)
        Ler dados da API / arquivo
        Validar estrutura, tipos e integridade

    2) Transformação (T — Transform)
        Limpeza de dados (nulos, duplicados, outliers)
        Padronização de colunas
        Conversões de tipo
        Criação de variáveis derivadas úteis

    3) Carga (L — Load)
        Estruturar dataset pronto para análise/modelagem

    4) Análise Exploratória (EDA)
        Estatísticas descritivas
        Distribuições
        Correlações
        Análise de churn vs variáveis

    5) Visualizações Estratégicas
        Gráficos interpretáveis
        Identificação de padrões de cancelamento
        Segmentos de maior risco

    6) Relatório de Insights
        Principais fatores de churn
        Perfis de clientes com maior risco
        Recomendações estratégicas para retenção

✅ Ferramentas que vou usar

        pandas → manipulação de dados
        numpy → cálculos numéricos
        matplotlib → gráficos
        seaborn (se permitido) → visualizações avançadas
        requests → consumo de API
